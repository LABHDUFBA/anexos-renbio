# Código incluído

Os scripts registram as transformações usadas na construção do corpus canônico e dos resultados agregados. Eles não são executáveis apenas com este pacote porque os dados-fonte do Telegram permanecem restritos.

As regras dos cinco eixos foram exportadas separadamente em `anexo-d/d3-regras-eixos.md`, sem os rótulos de chats usados em figuras exploratórias internas.
